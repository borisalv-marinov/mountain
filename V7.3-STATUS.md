# Mountain v7.3: status sheet (Thursday 19 Nov)

Order of importance, never swapped: **1 stability → 2 no tearing → 3 one style → 4 readable → 5 glass (last)**

v7.3 is the full check and fix: the look, the hidden part and security. Every fix has a lasting check. The full list, with proof per item, is the register: `docs/superpowers/specs/2026-11-18-v7.3-audit-register.md`.

## ✅ In main (merged 19 Nov 02:08, pull request #22)

Three full test runs on the merged code: 465 checks each, 0 problems (runs 44406293538, 44406426514, 44428497947).

| What was wrong | What changed |
|---|---|
| Scan found viruses but moved nothing | Found viruses go to quarantine again |
| Files of 100-400 MB were called clean without being scanned | They are scanned |
| A virus next to a password-protected file in the same zip was missed | Caught |

| Desktop right-click had Edit Mode, Lock, Logout; File Explorer had KDE-only items | Gone, from the very first sign-in |

| The test's "no program crashed" check could never see a crash | It sees them now |

## 🔍 Found, not ours

- **File Explorer's thumbnail helper crashes as it exits** (about 20 times per test run). The stack trace shows KDE's own signal handler reading freed memory while the helper shuts down. Nothing visible happens: the thumbnail is already shown. It needs a KDE fix; the test counts it on its own row and never hides it.

## ⚠️ Honest limits

- **Tearing and game feel can only be proven on your PC** (the test computer has no real graphics card): testufo.com and `mountain-report.txt`, please.
- **Active Protection checks a file after it is written** (within ~10 s), it cannot stop a program before it starts on this base.
- A program bigger than 2000 MB is listed "too large to scan" and you are told, but not quarantined (game installers are that big; Windows Defender does not block files it cannot scan either).
- Welcome passes the darkness check exactly at its limit.

## Still open (style)

Start stays open when you right-click the taskbar; sign-in screen details; Task Manager layout; Quick Settings split buttons; File Explorer Network and This PC look. Each is in the register with its screenshot.

# Mountain v7.2: status sheet (Monday 16 Nov)

Order of importance, never swapped: **1 stability → 2 no tearing → 3 one style → 4 readable → 5 glass (last)**

## ✅ Fixed (branch `mountain-v7.2`)

| What you saw | What changed |
|---|---|
| Task Manager: Quit needs two clicks | Apps now use Mountain's own list with an **End task** button, like Windows: it asks the app to close, and if it is still running after 3 seconds it is closed by force. KDE's "Quit" only asked once, so apps that hide in the tray (Steam, Discord) stayed open |
| Task Manager: App history | Checked. KDE's "Quit Application" button is gone (Windows has none there). The Download/Upload columns were always empty, so they are removed; the network chart below still shows traffic |
| Task Manager: no startup apps | Nothing was set to start, so the list was empty. Now installed apps such as **Steam, Discord, Spotify, Telegram, Heroic, Lutris** show as "Disabled", like Windows; press Enable to start one at sign-in (Steam starts in the tray) |
| Task Manager: side icons mixed | Every tab icon is black and white now |
| Settings: Apps icon is a square | The icon was missing and drawn as a solid block. Every icon in Settings (side bar **and** inside every page) is now the same black-and-white set |
| Add Brave | Brave installs on first boot, is in Start > Browsers and the Desktop Browsers folder, with the same tight sandbox as Edge |
| Language change: no pop-up | A click on **ENG** opens a Windows-style list: ENG English / БГ Bulgarian (the current one marked) and "More keyboard settings". Win+Space and Alt+Shift still switch straight away |

## 🆕 New

- **Game Mode** (on by default): while a game runs (Steam, Heroic, Lutris), the PC runs at full power; when you quit, your own power mode comes back. Switch: Settings > Gaming > Game Mode
- **Active Protection:** found and closed a hole: a virus renamed to `.txt` inside a freshly unpacked folder could slip through if the folder filled up in small bursts. Now everything landing in a new folder in Downloads, Desktop or Documents is scanned for 2 minutes. The VM check for this is now strict (it was info-only)

## ⚠️ Honest limits

- **Speed ("feels slow, not snappy")**: the VM already shows a lean system (search indexing off, Start menu opens in 170 ms, alt-tab 90 ms). What feels slow on your PC is most likely your graphics card or power settings, which the test computer can't show. **Please run the report command below once** so I can see your PC and fix the real cause.
- **Tearing** can only be proven on your PC: please also do the 30-second test at testufo.com.
- Accounts set up before v7.1 still keep their old taskbar right-click menu (fix planned next).

**Report command** (paste in Terminal, then send me `mountain-report.txt` from your Desktop):

```bash
{ echo "session=$XDG_SESSION_TYPE"; cat /proc/cmdline; dbus-send --session --print-reply --dest=org.kde.KWin /KWin org.kde.KWin.supportInformation; lspci -k | grep -A3 -Ei 'vga|3d'; coredumpctl list --since -2d --no-pager; journalctl -b -p err --no-pager | tail -100; } > ~/Desktop/mountain-report.txt 2>&1
```

# Mountain v6 (was v5.1): smooth, sharp, Task Manager, nearly unbreakable, complete

Brief: `docs/superpowers/prompts/2026-11-12-mountain-v6-smooth-secure-master-prompt.md`. Branch `mountain-v5.1`. Image checks: new phase 29.

## Threat model

| Threat | What stops it in Mountain | Undo / recovery |
|---|---|---|
| Remote attack | Firewall zone `mountain` (no open ports), no listening services by default, SELinux enforcing, v4 sysctls and kernel args, signed images | — |
| Malicious app or download | Flatpak sandbox (shipped apps can't see your home folder, only Downloads; Office also Documents/Desktop), virus scan on demand (ClamAV), read-only `/usr` | Quarantine folder, Restore from "Previous versions" |
| Malicious USB | Kernel lockdown is not forced (would break unsigned game drivers); USB drives mount without running anything (KDE never autoruns) | — (USBGuard skipped: blocks game controllers and dongles) |
| Stolen laptop | Disk encryption (LUKS) at install (guide), screen lock with password, sign-in password required | — |
| Broken update | Image updates are atomic, signed (cosign), only when you click; the previous version is always kept | "Go back to the previous version" in Settings › Updates, or pick it in the boot menu |
| User mistake | Hourly read-only snapshots of all home folders (Btrfs) | File Explorer › Previous versions: copy the file back |
| Ransomware | Snapshots are read-only and owned by the system, so a program running as you cannot change or delete them | Same as above |

## Rulings

1. **Task Manager = Plasma System Monitor with Mountain pages and three own faces.** Compared:
   - Plasma System Monitor (installed, Qt/Kirigami so it follows the BlackGlass colours, per-process CPU/RAM/disk/network/GPU, End process, history graphs). Missing Startup apps, Users, Services.
   - Mission Center (Flathub, GTK): Processes, Performance with model names, Services. Missing Startup apps, Users, App history; not black glass; a download at first boot.
   - Resources (Flathub, GTK): similar to Mission Center, no Services/Startup/Users.
   - Own app: would re-implement per-process network/GPU accounting that ksysguard already has.
   Picked the first: most native, nothing new to download, light. Mountain adds pages (Processes, Performance, App history, Startup apps, Users, Details, Services) and three small faces (Startup apps, Users, Services) plus a device-names face (CPU/GPU/disk models), all backed by `/usr/libexec/mountain-taskmanager`.
2. **App history** shows the history graphs (CPU, memory, network, GPU over time) plus per-app CPU time since sign-in: Plasma keeps no per-app usage store across reboots.
3. **Ctrl+Shift+Esc** opens Task Manager (Ctrl+Esc kept). It is in the start menu and in the Start button's right-click menu (Windows' own Win+X spot); Plasma's panel menu takes no custom entries.
4. **End task does not ask** (like Windows); Details keeps the confirmation.
5. **Security page** lives in Settings › Privacy & security (like Windows 11, where Windows Security sits at the top of that page), plus a "Security" start-menu entry that opens it.
6. **Antivirus = ClamAV, on demand only.** `clamscan` runs when you click Scan now; definitions download only then (or with Updates). No on-access scanning, no scheduled scans, no daemon: zero RAM or CPU while you play. Steam, Proton and game folders are skipped. Found files move to a quarantine folder that nothing can run from.
7. **Skipped (logged):** rkhunter/chkrootkit (false alarms on an image-based system), USBGuard (blocks controllers and dongles), fail2ban (nothing listens), clamd/on-access (RAM), kernel lockdown by default (breaks unsigned NVIDIA/game modules without Secure Boot; it is a documented opt-in and shown in the Security page).
8. **Flatpak tightening only for the shipped non-gaming apps** (Discord, Vesktop, Edge, Firefox, OnlyOffice): no home folder, Downloads allowed, Office also Documents and Desktop. Game launchers (Heroic and anything you install later) keep their own permissions, so games are untouched.
9. **Snapshots**: hourly, read-only, keep the newest 24 plus one per day for 7 days; at under 10 % free disk only the newest 3. Needs `/var/home` to be a Btrfs subvolume (the installer's default layout); otherwise the Security page shows "off". Snapshots are local, not a download, so the "no background updates" rule is kept.
10. **Two narrow no-password actions** for signed-in users: start the virus-definitions update and take a snapshot. Everything else admin still asks for the password; `sudo` always asks.
11. **App windows are solid black** (no see-through); glass and blur stay on the taskbar, start menu, flyouts and menus. Fixes the bleed-through, raises contrast, and saves the blur cost behind every window.
12. **Fonts:** slight hinting with RGB subpixel rendering (crisp at 100 % and 125 %).
13. **Speed measured with Enter** on the selected item in File Explorer (the same "open" action a double-click triggers) and with the time QEMU sends the key, so the harness overhead is no longer counted.
14. **Budgets in the VM** are the v5.1 baselines + 20 % (software rendering); the real-PC budgets (500/150/100 ms) are reported next to them.
15. **Minimize = squash** (Windows-like) instead of magic lamp (Mac-like).
16. **Try Mountain:** the browser asks the VM to match the window size (`resizeSession`), so there's no scaling blur; QEMU's VNC sends lossless pictures.

## v6 addendum rulings (sections 8–19)

17. **Font stays Noto Sans** (listed as acceptable; already crisp with hinting). Selawik is not in Fedora and vendoring a font download is against the build rule; Inter would reflow every surface for little gain.
18. **Icons stay We10X** (Windows-style, licensed in Fedora); no Fluent theme is packaged in Fedora.
19. **Start menu:** 18 pins in 3 full rows (Firefox, Edge, File Explorer, Steam, Settings, App Store, Notepad, Calculator, Photos, Media Player, Snipping Tool, Task Manager, VS Code, OnlyOffice, Discord, Heroic, Terminal, Security), so no page indicator is needed; Welcome unpinned; "VS Code" name; Recommended shows a calm hint line when empty.
20. **Text files open in Notepad** (KWrite) like Windows; code and Markdown stay in VS Code.
21. **Apps:** Calculator (KCalc), Clock (KClock), Paint (KolourPaint), Camera (Kamoso), Sound Recorder (KRecorder), Scanner (Skanlite), Snipping Tool (Spectacle), Photos (Gwenview), Media Player (Haruna) — Fedora packages. Calendar (Merkuro) and Weather skipped: they run background services.
22. **Keyboard:** English, Bulgarian phonetic and BDS; Alt+Shift and Win+Space switch; the tray shows ENG/БЪЛ/БДС. UI stays English; Bulgarian is selectable in Settings › Time & language.
23. **Shortcuts:** Win+I, Win+R, Win+E on the apps; Win+Tab = Overview, Win+Z = tile editor. Win+X stays on right-click Start (no Plasma menu to bind). Alt+F4 on the desktop does nothing (Plasma has no such dialog; Win+L/Start's power button cover it).
24. **Notification center:** Plasma's own (bell in the tray, Do Not Disturb inside); the clock opens the calendar. Widgets (Win+W) skipped: they cost RAM and CPU all the time.
25. **Taskbar:** 48 px, not floating, show-desktop button at the far right; jump lists, pin/unpin and hover previews are Plasma's own.
26. **Recovery:** Settings › System › Recovery → Updates page: Go back (rollback, vm-tested), Reset this PC (keep my files) = `rpm-ostree reset` (drops packages and overrides added on this PC; apps and files stay). "Remove everything" means reinstalling; no installer this round, so it is documented only.
27. **File History:** right-click › Restore previous versions opens the same folder in the newest snapshot.
28. **Phone Link = KDE Connect**, started only when opened (still no autostart or D-Bus activation); its firewall ports are allowed, but nothing listens until you open it. Google Drive via Online accounts (kio-gdrive); OneDrive skipped (no free KIO backend).
29. **Gaming:** MangoHud loaded in games and hidden until Win+G. Game mode skipped (Bazzite removed gamemode; the LAVD scheduler does the job). VRR/HDR are in Settings › Display.

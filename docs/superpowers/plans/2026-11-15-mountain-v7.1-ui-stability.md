# Mountain v7.1: stable, tear-free, one Windows style — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every window looks like one Windows 11 system, nothing tears or draws half-rows, nothing crashes. Proven by tests that look at the screen the way a user does, run before and after every fix.

**Architecture:** First build a user-view test kit (Phase 0) and run it on today's image to record what is broken. Then fix in strict priority order: stability → no tearing → one style → contrast → transparency (last). Fixes are system-wide config Mountain already ships (`/etc/xdg`, `/etc/environment`, Flatpak system overrides, kernel arguments, theme files) or build-time patches in the `files/scripts/process-table.sh` style. `tests/check-image.sh` fails the build if any of it is missing.

**Tech Stack:** Bazzite (Fedora Atomic), Plasma 6 / KWin Wayland, Kvantum, GTK3/4, Flatpak, BlueBuild, GitHub `vm-test.yml` (QEMU, llvmpipe), Python + Pillow + Tesseract on the runner.

**Spec:** Owner messages of 2026-11-15 (4 screenshots + follow-up: "one universal style like Windows", "backed by the kernel", "tests before and after every implementation", "transparency lowest, stability highest", "tearing must not be possible", "test from the user perspective"). ## Global Constraints

- **Priority order, never swapped:** 1 stability, 2 no tearing, 3 one style, 4 contrast/readability, 5 transparency. A lower item never ships if it costs a higher one.
- **Before/after rule:** every task starts by running its user-view checks on the current image (expected FAIL, saved as `before`) and ends by running them on the new image (PASS, saved as `after`). The report shows both screenshots side by side.
- **"Looks right" is tested, not assumed:** a screenshot without a pixel/OCR assertion is not a test.
- "Backed by the kernel" = system level: kernel display arguments (atomic modesetting, NVIDIA KMS) + system-wide config in `/etc` that every user and every app gets + a build that refuses to ship without them. (The kernel itself doesn't draw windows.)
- Two fully clean `vm-test` runs in a row on one commit before merge. Owner checks tearing on real hardware.
- Windows 11 look is the top visual rule; UI gaps are never "cosmetic".

## Review Focus

1. **Real GPU differs from the VM** (VM = software drawing, 23 fps). Tearing is only confirmed when the owner passes the real-hardware test in Task 0.1.
2. **Games:** `AllowTearing=false` means fullscreen games can't tear either (owner's rule). Frame rate must not drop: Task 2.1 keeps `vm-test`'s frame-pacing check and the owner checks one game.
3. **Light apps on a dark system:** Firefox/Edge/ONLYOFFICE in light mode would break "one style". Task 3.2 opens each and checks the window body is dark.
4. **Existing users:** settings already in `~/.config` override `/etc/xdg`. Every changed key gets a one-time migration in `mountain-user-setup` with its test in `tests/test-user-setup.sh`.
5. **Bulgarian typing:** after the layout switch, Alt+Shift still toggles and Cyrillic letters land correctly (я on Q, в on W).

- [ ] **Step 3:** Wire into vm-test for: Start search (type "settings", "firewall", "steam", one key at a time, check after **every** key), Shut Down dialog (`must_read: ["Shut down"]`), File Explorer (`must_not_read: ["0 B free"]`), Settings, Task Manager, Run, Win+X, every flyout.

### Task 0.3: One-style check across every app

**Files:** Create `tests/vm/stylecheck.py`, `tests/vm/style-reference.json`; modify `vm-test.yml` to open **every** Start menu app (all pins incl. Firefox, Edge, Steam, VS Code, Discord, ONLYOFFICE, Heroic, App Store, Lutris), one at a time, maximized, then screenshot.

**Interfaces:** `stylecheck.py SHOT.png --window x,y,w,h` → JSON `{titlebar_h, titlebar_rgb, body_rgb, buttons_match, font_px}`; compares with `style-reference.json` (taken from File Explorer, the reference app).

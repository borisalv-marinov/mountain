# Mountain v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkboxes.

**Goal:** Windows 11 start menu, a new layered-peaks logo everywhere (incl. avatar), glass look, VS Code for text/code, smoother, hardened without breaking gaming/coding/AI, owner docs; carry over v3 follow-ups.

**Architecture:** Same recipe and test layout as v3 (`recipes/common.yml`, `files/system`, `files/scripts`, `tests/check-image.sh` new phases 25–29, real-use `vm-test.yml`). Community code is vendored only when it is pure source in a Fedora/Flathub-free way (Menu 11 Enhanced QML, GPL-2.0+).

**Spec:** owner's v4 message (relayed 2026-11-12) + `docs/superpowers/prompts/2026-11-11-windows-polish-master-prompt.md` hard rules.

## Global Constraints
- No downloads at build time beyond Fedora repos, recipe repos, Flathub (rules out COPR blur forks).
- No brand logos; no secrets; no passwordless sudo in the shipped image; repo stays public.
- Old check phases never weakened. Phase 3's Exec assertion is replaced by an equally strict one (same Edge + URL) because web apps now get their own window class.

| Windows 11 start menu | [Menu-11-Enhanced](https://github.com/kurojs/Menu-11-Enhanced) (QML only, GPL-2.0+, Plasma 6.0+, last commit 2025-12-24; fork of [menu-11-next](https://github.com/Eisteed/menu-11-next)); [Menu11](https://github.com/prateekmedia/Menu11) deprecated; [OnzeMenu](https://github.com/adhec/OnzeMenuKDE) stale (2023). | Vendor Menu-11-Enhanced (pinned grid, All apps, search on top, recent docs renamed "Recommended", centered). | Blur / acrylic | [Better Blur DX](https://github.com/xarblu/kwin-effects-better-blur-dx) and [forceblur](https://copr.fedorainfracloud.org/coprs/yohane-shiro/kwin-effects-forceblur) only via COPR (third-party repo; rebuilt per KWin release) — not allowed. | Stock KWin blur + translucent Kvantum GlassDark (already blur-aware) + translucent panels; lite mode still turns blur off on weak GPUs. Try VM shows the glass (owner must see it). |
| Avatar placeholder | Kickoff/lock screen read `~/.face.icon` / AccountsService, else a letter circle ([KDE 384107](https://bugs.kde.org/show_bug.cgi?id=384107), [470652](https://bugs.kde.org/show_bug.cgi?id=470652)). | Ship the logo as `/etc/skel/.face.icon` and in `/usr/share/plasma/avatars`. |
| VM flicker/stutter | Plasma-in-VM flicker is a Mesa/KWin issue ([KDE 472016](https://bugs.kde.org/show_bug.cgi?id=472016)); virgl perf bug [481374](https://bugs.kde.org/show_bug.cgi?id=481374). Runners have no GPU: llvmpipe. | VM: keep virtio-vga + local cursor, more vCPUs for llvmpipe, measure. OS: scx_lavd scheduler (Bazzite ships scx_loader, disabled), fewer services. |
| Hardening | secureblue [55-hardening.conf](https://github.com/secureblue/secureblue/blob/live/files/system/usr/lib/sysctl.d/55-hardening.conf); its hardened_malloc breaks Electron (VS Code, Discord) and Steam; usbguard blocks new controllers. | Take the gaming-safe sysctls + kargs, a closed firewall zone, SELinux enforcing check; skip hardened_malloc, usbguard, io_uring off, icmp off. |

Probe of `mountain:latest` (2026-11-12): Kvantum Qt6 style present; no extra KWin effects; `scx_loader` installed but disabled (`default_sched` unset); firewalld default zone **FedoraWorkstation opens TCP/UDP 1025–65535**; SELinux enforcing; sshd/cups disabled; avahi, ModemManager, bluetooth enabled; `kernel.yama.ptrace_scope=0`; no `/usr/lib/bootc/kargs.d`; firewalld ships `steam-streaming` and `steam-lan-transfer` services.

## Rulings
1. Start menu = vendored Menu 11 Enhanced (strings: "Search for apps, settings and documents", "Recommended"); pinned list = v3 pins.
2. Glass: no COPR blur; stock blur. Try VM: lite mode off and blur on so the owner sees the look.
3. Text/code files open in VS Code (owner's choice); Notepad stays for quick edits via Open with.
4. Firewall: own `mountain` zone = default deny incoming except DHCPv6, mDNS, Samba client, Steam Remote Play + LAN transfer.
5. Web apps: each cloud-gaming app runs in its own Edge profile with its own window class → its own taskbar icon and name (one sign-in per app).
6. Not done (no safe way): "Dolphin" in title bars (app name is compiled in), Details pane default (binary window state), lock-screen greeting (compiled screen locker), drag-icon bug (upstream).

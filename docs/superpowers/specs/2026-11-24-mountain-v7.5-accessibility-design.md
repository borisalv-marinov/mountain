# Mountain v7.5: Accessibility (design / PRD)

Date: 2026-11-24. Branch: `v75-gaps` (from main ce29027, v7.4).
Status: written by the lead; owner rule "don't ask, decide and say so" applies. Every choice below is the lead's call.

## 1. Why

The owner asked for a senior-engineer pass: compare Mountain with other systems and find what it lacks.
The biggest gap is **Accessibility**. Windows 11 and every big Linux desktop ship a screen reader, a magnifier,
colour filters, a bigger pointer, sticky keys and "turn off animations". Mountain's Settings > Accessibility has
one row (Night light). A blind or low-vision person cannot use Mountain today. A colour-blind gamer cannot fix colours.
Bazzite's KDE already has the parts (Orca, KWin zoom, KWin colour-blindness filter, KWin sticky keys).
They are just not installed, not switched on, or not reachable from Mountain's Settings.

## 3. Goals, non-goals, anti-goals

Goals (this round):
1. Settings > Accessibility gets a native Mountain page with Windows 11's names:
   **Narrator**, **Magnifier**, **Color filters**, **Mouse pointer size**, **Sticky keys**, **Animation effects**,
   **Transparency effects**, **Night light** (moved row, page unchanged), **Text size** (opens Display, honest description).
2. Windows' shortcuts work: **Win+Ctrl+Enter** Narrator on/off, **Win+Plus** zoom in, **Win+Esc** magnifier off,
   **Win+Ctrl+C** colour filter on/off.
3. Orca is in the image and talks (espeak-ng through speech-dispatcher).
4. Bulgarian text for every new string.
5. Lasting checks: a unit test, `check_phase47`, and vm-test rows that judge it like a user (page title over AT-SPI,
   the setting really took effect in KWin, Orca really runs and stops).

Non-goals: contrast themes, text-size slider, on-screen keyboard, live captions, fingerprint, Shift×5 sticky-keys trigger.

Anti-goals (a failure even if it "works"):
- Anything that can crash KWin or Plasma, or adds tearing (priority 1 and 2). Every change is a KWin effect toggle or a
  config key that KDE itself writes; no new KWin script, no new daemon.
- A switch that shows "On" while nothing happened. The page reads back real state after every click.
- Narrator that cannot be turned off by keyboard alone (Win+Ctrl+Enter must always stop it).
- English left in a Bulgarian session.

## 4. Constraints found in KDE's source (Plasma 6.5)

- `kaccess` (Plasma's accessibility daemon) turns the screen reader on by writing `kaccessrc [ScreenReader] Enabled`,
  setting `gsettings org.gnome.desktop.a11y.applications screen-reader-enabled true` and running `orca --replace`.
  Off = gsettings false (Orca quits on its own when that key goes false). Mountain does the same steps itself, so it
  does not depend on kaccess being alive on Wayland.
- KWin Zoom is enabled by default; shortcuts `view_zoom_in` (Meta+Plus, Meta+=), `view_zoom_out` (Meta+-),
  `view_actual_size` (Meta+0). They can be fired with `org.kde.kglobalaccel.Component.invokeShortcut` on `/component/kwin`.
  Zoom level is not readable, so Magnifier is two buttons (Zoom in / Back to normal), not a fake on/off switch.
- KWin `colorblindnesscorrection` effect: off by default; `kwinrc [Effect-colorblindnesscorrection] Mode`
  0 = protanopia, 1 = deuteranopia, 2 = tritanopia. Loaded/unloaded via `org.kde.kwin.Effects.loadEffect/unloadEffect`.
- KWin `stickykeys` plugin: enabled by default, reads `kaccessrc [Keyboard] StickyKeys` through KConfigWatcher,
  so `kwriteconfig6 --notify` applies it live.
- Pointer size: `plasma-apply-cursortheme <current theme> --size N` (it refuses a size the theme lacks and says so).
  GTK apps: `gsettings org.gnome.desktop.interface cursor-size N`.
- Animations: `kdeglobals [KDE] AnimationDurationFactor` (Mountain's default is 0.75 in /etc/xdg/kdeglobals).
- Extra shortcuts: a NoDisplay `.desktop` with `X-KDE-Shortcuts=` (Mountain already does this for Win+Shift+S),
  so they work for existing accounts too, not only new ones.

## 5. Design

### 5.1 Helper `files/system/usr/libexec/mountain-accessibility` (bash, one file)

```
mountain-accessibility status                      prints narrator= filter= cursor= sticky= animations= (one per line)
mountain-accessibility narrator on|off|toggle
mountain-accessibility filter off|protanopia|deuteranopia|tritanopia|toggle   (toggle = off <-> last used, default deuteranopia)
mountain-accessibility cursor 24|32|48|64
mountain-accessibility sticky on|off
mountain-accessibility animations on|off           (on = 0.75, Mountain's default)
mountain-accessibility zoom in|off
```
- Only fixed words are accepted; anything else exits 2 with usage (the page passes only its own literals).
- Writes only the user's `~/.config` and user gsettings; never root.
- `filter toggle` remembers the last filter in `~/.local/state/mountain/color-filter`.
- `narrator on` starts Orca detached (`setsid -f orca --replace`) so the Settings window can close.
- Commands it calls are looked up on PATH, so the unit test can put stubs first (same style as test-lite-mode).

### 5.2 Settings page `AccessibilityPage.qml`

Same building blocks as NightLightPage (GlassCard, PillSwitch, GlassButton, GText, PageTitle). Rows:
Narrator (switch + "Win+Ctrl+Enter"), Magnifier (Zoom in / Back to normal buttons + "Win+Plus, Win+Esc"),
Color filters (Off / Red-green (green weak) / Red-green (red weak) / Blue-yellow, + "Win+Ctrl+C"),
Mouse pointer size (Normal / Large / Larger / Largest = 24/32/48/64), Sticky keys (switch), Animation effects (switch).
After each click the page re-runs `status` and shows what is really set.
`main.qml`: category `accessibility` gets the page (`page: "accessibility"` in nativePages) and keeps the Night light,
Transparency effects and Text size rows as items, so search finds "narrator", "magnifier", "colour blind", "cursor".

### 5.3 Shortcuts (new NoDisplay desktop files)

- `org.mountain.narrator.desktop`: `X-KDE-Shortcuts=Meta+Ctrl+Return`, Exec `mountain-accessibility narrator toggle`
- `org.mountain.colorfilter.desktop`: `X-KDE-Shortcuts=Meta+Ctrl+C`, Exec `mountain-accessibility filter toggle`
- `org.mountain.magnifier-off.desktop`: `X-KDE-Shortcuts=Meta+Esc`, Exec `mountain-accessibility zoom off`

### 5.4 Image

`recipes/common.yml` dnf install: `orca` (pulls speech-dispatcher + espeak-ng).

### 5.5 Tests (written first, TDD)

1. `tests/test-accessibility.sh` (CI lint job): stubs `kwriteconfig6`, `kreadconfig6`, `gsettings`, `dbus-send`,
   `orca`, `setsid`, `pkill`, `plasma-apply-cursortheme` that log their arguments; asserts each subcommand writes the
   right key/value and calls the right D-Bus method, `toggle` remembers the last filter, bad input exits 2,
   `status` prints all five keys.
2. `check_phase47` in `tests/check-image.sh`: helper is 755, page file present, desktop files with the four shortcuts,
   `/usr/bin/orca` present (image only), category wired in main.qml.
3. `tests/test-i18n.sh` already fails on any new English string without Bulgarian; `tools/po2mo.py --check` on the .mo.
4. `vm-test.yml`: Settings opens on `accessibility` and its title is read over AT-SPI (added to the existing page loop);
   rows: color filter on → `isEffectLoaded colorblindnesscorrection` true, off → false; sticky on → kaccessrc true;
   narrator on → `pgrep orca` and gsettings true; narrator off → Orca gone within 10 s; cursor 48 → kcminputrc 48;
   screenshot `settings-accessibility` for the QA reviewer.

## 6. Follow-ups (not this round, in order)

1. Contrast themes: Mountain's own windows hard-code colours (e.g. `#5AB0FF`, white rgba), and Kvantum ignores KDE colour
   schemes, so a real high-contrast mode means a palette pass over every org.mountain.* plasmoid plus Kvantum + GTK themes.
2. Text size slider (font point sizes in kdeglobals + GTK text-scaling-factor + Mountain QML).
3. Fingerprint sign-in (fprintd + SDDM/lock-screen PAM) under Sign-in options.
4. On-screen keyboard (Plasma Keyboard needs `kwinrc [Wayland] InputMethod`, which Mountain blanks today).

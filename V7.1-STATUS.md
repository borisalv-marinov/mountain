# Mountain v7.1: status sheet (Sunday 15 Nov)

Order of importance, never swapped: **1 stability → 2 no tearing → 3 one style → 4 readable → 5 glass (last)**

## ✅ Fixed (in branch `mountain-v7.1`, being built and tested now)

| What you saw | What changed |
|---|---|
| Tearing, smearing, half-drawn rows in Start search | App windows are solid (they were see-through, so the screen redrew the blur behind every app). Blur grain is off. Tearing is switched off for everything, games included |
| Settings shows as "Plasma" | The taskbar shows it as **Settings** with its own icon |
| Keyboard pop-up stuck on screen | Gone (Windows has none) |
| "Bulgarian (traditional phonetic)" | Now **Bulgarian (Phonetic)**, the same layout as Windows. Existing accounts switch over too |
| Taskbar right-click | Shows **Task Manager** and **Taskbar settings**, like Windows |
| Task Manager | One search box (was two), no KDE "Quit Application" button, an icon on every background process, soft grey selected row |
| Pop-ups hard to read | 95% solid (was 85%), so the wallpaper no longer shows through |
| Shut Down dialog | The choice ("Shut down") was invisible; it now shows. Run uses the same dropdown look |
| Different colours in every window | Mountain's windows (Settings, Run, Shut Down) now use the same neutral greys as every app. Selected rows are soft grey everywhere, like Windows 11 |
| Firefox, Discord and other non-KDE apps | They now get the same dark look settings, system-wide |
| Notepad | Opens a blank page (no "Recent files" page) |
| File Explorer "0 B free" | Home opens on its real path, so free space is shown |

## 🧪 New tests that look like a person

- **Opens every app in Start**, one by one: its window must be dark like the rest of the system
- **Types in Start search one letter at a time** and checks the rows can be read
- **Lists every window that pops up**: its type and whether it draws its own title bar
- **Stability:** the desktop and window manager must never restart; no program may crash
- **Tearing:** tearing switched off and the session is Wayland (the old display system, X11, tears)
- Run **before** each fix (old image) and **after** (new image)

## ⚠️ Honest limits

- **Tearing can only be proven on your PC.** The test computer draws without a real graphics card. Please do the 30-second tearing test at testufo.com and send the report file (command below)
- **Accounts already set up** keep their old taskbar: the new right-click menu shows on new accounts
- **Browsers, Steam, VS Code and Discord** still draw their own title bars, as they do on Windows

**Report command** (paste in Terminal, then send me `mountain-report.txt` from your Desktop):

```bash
{ echo "session=$XDG_SESSION_TYPE"; cat /proc/cmdline; dbus-send --session --print-reply --dest=org.kde.KWin /KWin org.kde.KWin.supportInformation; lspci -k | grep -A3 -Ei 'vga|3d'; coredumpctl list --since -2d --no-pager; journalctl -b -p err --no-pager | tail -100; } > ~/Desktop/mountain-report.txt 2>&1
```
